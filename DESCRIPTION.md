# 🐦 TDS Analysis of Pigeon Flocks

## 📌 Описание проекта

Этот проект предназначен для анализа синхронности движения птиц в стае на основе их GPS-траекторий.

Данные представлены в виде CSV-файлов, содержащих координаты (X, Y) нескольких птиц во времени.

Цель:

- определить различия между типами полёта:
  - **маршрутный полёт (route / homing)**
  - **локальное движение (around home)**
- использовать метрику **Time Delay Stability (TDS)** для анализа согласованности поведения стаи

---

## 🧠 Основная идея

Если птицы:

- летят по маршруту → они движутся согласованно → **TDS высокий**
- кружат → поведение хаотичнее → **TDS ниже**

---

## 📂 Формат входных данных

CSV файл содержит:

```
Time(sentisec);X_A(m);Y_A(m);X_B(m);Y_B(m);...
```

### Где:

- `Time` — время (в сотых долях секунды)
- `X_*`, `Y_*` — координаты птиц
- каждая строка — состояние всей стаи в момент времени

---

## ⚙️ Как работает алгоритм

### 1. Загрузка данных

- читаются CSV-файлы
- извлекаются координаты всех птиц
- данные преобразуются в временные ряды

---

### 2. Разделение сигналов

Для каждой птицы формируются:

- сигнал X(t)
- сигнал Y(t)

Анализ проводится:

- отдельно по X
- отдельно по Y

---

### 3. Попарный анализ птиц

Для каждой пары птиц:

```
(A, B), (A, C), (B, C), ...
```

рассчитывается TDS.

---

### 4. Деление на окна

Временной ряд разбивается на окна фиксированного размера:

```
[окно1][окно2][окно3]...
```

Это необходимо, потому что поведение стаи меняется во времени.

---

### 5. Поиск лагов

В каждом окне:

- один сигнал сдвигается относительно другого
- ищется сдвиг (лаг), при котором сигналы максимально похожи

Результат:

```
lags = [2, 2, 3, 2, 2, 1, ...]
```

---

### 6. Расчёт TDS

TDS измеряет:

> насколько стабильно лаг остаётся одинаковым во времени

- стабильный лаг → высокая синхронность → TDS ≈ 1
- случайные лаги → слабая связь → TDS ≈ 0

---

### 7. Формирование матрицы связей

Результаты собираются в матрицу:

> A B C

```
A 1.00 0.85 0.80
B 0.85 1.00 0.90
C 0.80 0.90 1.00
```


Это **heatmap синхронности стаи**

---

## 📊 Визуализация

Проект строит несколько типов графиков:

### 1. Траектории птиц
- движение на плоскости
- позволяет визуально разделить типы полёта

---

### 2. Координаты во времени
- X(t), Y(t)
- показывает динамику движения

---

### 3. Heatmap TDS
- матрица связей между птицами
- позволяет увидеть:
  - ядро стаи
  - слабосвязанные элементы
  - выбросы

---

## 🧪 Экспериментальная часть

### Гипотеза:

- маршрутный полёт → высокий средний TDS
- локальный полёт → более низкий TDS

---

### План анализа:

1. Построить траектории
2. Визуально разделить стаи на группы
3. Рассчитать TDS для каждой стаи
4. Сравнить:
   - средний TDS
   - распределение значений
   - структуру матриц

---

## ⚙️ Параметры

### Размер окна (window)

Ключевой параметр:

- маленькое окно → шум
- большое окно → сглаживание

Рекомендуется тестировать несколько значений.

---

### Частота дискретизации

Time задан в sentisec:

> 1 единица = 0.01 сек


Важно учитывать при выборе окна.

## 🧠 Интерпретация результатов

Высокий TDS означает:

- птицы повторяют друг друга
- есть лидер/структура
- движение согласованное

Низкий TDS:

- независимое поведение
- хаотичность
- слабая связь

## Гистограмма СКО запаздываний
После графика стабильности лага по номеру окна полезно приводить гистограмму значений СКО найденных лагов для всех пар птиц в данном полёте.
Что показывает этот рисунок:
- если основная масса значений сосредоточена слева, при малом СКО, значит для многих пар лаг меняется мало и структура запаздываний во времени достаточно устойчива;
- если распределение широкое или сдвинуто вправо, значит лаги заметно гуляют от окна к окну, а синхронность между птицами менее устойчива;
- возможный порог удобно выбирать по границе между плотной левой частью распределения и более редким правым хвостом;
- вертикальные линии среднего и медианы помогают быстро оценить типичный уровень разброса лагов.
Для этой гистограммы разумно брать больше карманов, чтобы форма распределения была видна лучше; в текущей реализации используется 20 карманов.
Такой рисунок стоит располагать сразу после графика изменения лага по номеру окна, поскольку эти два графика дополняют друг друга:
- график по номеру окна показывает, как ведёт себя лаг во времени для одной характерной пары;
- гистограмма СКО показывает распределение устойчивости лагов уже по всем парам птиц данного полёта.
